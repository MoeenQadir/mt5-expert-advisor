# MT5 Expert Advisor — Institutional-Grade Trading Bot

A sophisticated MetaTrader 5 Expert Advisor featuring multi-timeframe analysis, dynamic risk management, configurable strategy parameters, and comprehensive trade management capabilities designed for research and prop firm environments.

## Features

- Multi-timeframe trend analysis (H4, H1, M15)
- Dynamic position sizing algorithms
- Stop-loss/take-profit with breakeven and trailing options
- Partial position closing capabilities
- News filter and trading session filters
- Maximum spread and slippage protection
- Trade execution error handling and retry logic
- Daily loss limits and max drawdown protection
- Comprehensive CSV trade logging
- Strategy parameter input groups for optimization

## Stack

- MetaTrader 5
- MQL5
- Technical Analysis
